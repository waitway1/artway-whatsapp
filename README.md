# ArtwayWhatsapp

ArtwayWhatsapp 是一个 Windows 桌面多账号工作台。当前版本提供账号浏览器档案隔离和客户管理：

- 每个账号使用独立的 Electron 持久会话分区
- Cookie、IndexedDB、缓存与 WhatsApp 登录状态互不共享
- 每个档案固定浏览器语言、时区、屏幕参数和处理器线程数
- 手动扫描二维码登录 WhatsApp Web
- 支持客户车型分类、消息模板和逐位文字群发；不包含养号或自动回复

## 本地开发

```powershell
npm install
npm run dev
```

## 验证

```powershell
npm test
npm run build
```

## Windows 安装包

```powershell
npm run pack:win
```

安装包生成在 `release` 目录。

## 数据位置

账号清单保存在 Electron 的应用数据目录。每个账号的浏览器数据位于独立的 `Partitions` 子目录中。删除账号档案时会清除对应站点存储和缓存。

群发通过所选账号的 WhatsApp Web 页面进行操作，需要已登录且网络可用。使用者应遵守 WhatsApp 条款并只管理自己有权使用的账号。

## 客户管理

顶部小人图标为客户入口。页面顶部提供“下载模板”，搜索栏旁的“导入客户”用于上传。

模板包含“客户名单”和“填写说明”两张工作表：

- 仅保留名称、国家、号码三列，均为必填。
- 新客户导入后状态默认为“待联系”。
- WhatsApp号码填写含国际区号的7–15位纯数字，不含+或空格。
- 保留工作表及三列表头的原顺序，客户名单从第2行开始填写。说明页无需删除。
- 单次最多2000条，格式或任意行资料不合格时整份文件拒绝导入；重复号码自动跳过。

客户资料、联系人和跟进记录保存在本地；可搜索、编辑、确认删除和打开账号内的WhatsApp会话。客户页不再显示国家和状态筛选器。支持通过群发页面创建并执行文字发送任务。

## WhatsApp 加载

账号页面保留独立磁盘缓存；切换客户页面或账号不会节流二维码初始化。只向 WhatsApp 来源开放通知及持久存储权限，并预连接主站和静态资源域名。同一数据目录仅允许一个应用实例，重复启动会激活原窗口，避免多个进程竞争账号存储。

网络沿用系统代理。首次打开新档案需下载 WhatsApp 静态资源，速度取决于网络与代理；重开已有档案会复用缓存，不清理登录数据。

## 按车型管理客户

导入模板继续使用名称、国家、号码三列。导入窗口中填写“所属车型”，整批客户归入该车型；文件名包含 Ford_Ranger_T9 或 Jetour_T2 时会预填对应车型。

客户页面提供各车型及未分类入口和数量。客户详情可编辑所属车型，多个车型用逗号分隔。重复号码再次导入其他车型时补充车型分类，不覆盖客户名称、国家和跟进记录。

## 联系记录与删除排除

客户列表的国家单独显示，不在名称下重复显示。联系次数来自已记录的联系事件；时钟图标悬停或键盘聚焦可查看联系日期，同日多次联系会合并显示次数。

在客户详情点击“记录一次联系”并确认，会为今天（上海时区）增加1次记录。仅打开WhatsApp会话不计为已联系，也不会读取聊天内容自动推断次数。联系记录只显示日期。

删除客户时同时持久保存排除记录。后续导入按号码（含历史号码）跳过已删除客户，并报告跳过数量。重复导入不会覆盖手工改名、备注和联系记录。数据写入采用临时文件加原子替换；版本升级保留已有客户数据及其他元数据。

## 消息群发与保存模板

在小人图标进入客户页，选择车型后点击“群发消息”。在当前车型客户中勾选收件人、选择已登录账号、编写消息，再检查预览并确认开始。不会在打开页面、选用模板或启动软件时自动发送。

- 支持文字、图片和文件，每次1–200位客户。消息按输入内容原样发送，无变量按钮和任务名称输入。
- 填写模板名称可保存、修改、另存为或删除模板；模板与任务结果持久保存在应用数据目录的campaigns.json，模板可同时保存图片与附件。
- 默认排除最近7天联系过的客户，可自行调整为0–365天；发送间隔为3–300秒。
- 成功仅在新的对应消息出现WhatsApp发出确认后成立，不代表对方已读。同一客户本次文字、图片和附件全部成功后恰好增加1次联系，日期按上海时区记录。
- 明确失败与未确认分开显示，均不增加联系次数，不会自动重试。未确认时请在账号内人工核实，避免重复发送。
- 支持暂停、继续剩余客户、停止任务和查看历史。暂停/停止在当前客户确认处理结束后生效。应用退出时未完成的任务不会自动重发；中断的当前项标记待核实，其余标记未发送。
- 发送前会核验号码及会话；已有草稿、账号未登录、网络故障或无法核验收件人时暂停处理。WhatsApp页面结构变化可能需要更新适配器，无法确认时不会当作成功。
- 群发期间账号浏览器由任务占用，不能同时手工操作该账号；可暂停后检查账号。
- 列表五列采用相等固定列宽，切换车型不会因内容长度改变表头位置。

验证使用隔离账号及本地模拟页面，覆盖成功、明确失败、确认超时、暂停/停止和重启恢复；未向真实客户试发。

## 图片、附件与号码测试

消息编辑区的“添加图片”“添加附件”可选择本地文件，最多10个，每个最大50MB。图片可预览，文件可移除，允许仅发送图片或附件而不填写文字。文件会复制到应用数据目录的message-attachments中，保存模板后不依赖原文件位置。

切换到“输入号码测试”，填写含国际区号的7–15位号码并确认，只会发送给这个号码。测试不会新建客户；若号码匹配已有客户，所有内容确认成功后记录一次联系。已删除的号码仍禁止发送。测试模式不使用“近期联系排除”，客户模式继续遵守原排除设置。

文字、图片、附件依次发送，全部确认成功才记录一次联系。部分成功、其余失败或未确认时标记待核实，显示原因，不增加联系次数，不自动重发。

## 后台与系统托盘

点击窗口X会隐藏窗口并从任务栏移除，保留右下角系统托盘图标和后台任务。单击或双击托盘图标、右键选择“打开 ArtwayWhatsapp”、再次双击桌面快捷方式均可恢复窗口。只有托盘菜单“退出”会正常结束应用；系统关机或外部结束进程仍可终止程序。

## WhatsApp Web 版本兼容

联系人已保存名称且消息ID不再包含号码时，发送前通过“新聊天”按完整号码搜索唯一结果，选择后绑定该会话标题和页头，防止将名称当作号码。联系人选择与发送按钮使用 Chromium 原生鼠标事件，兼容页面的指针事件处理。

成功判定兼容旧data-icon回执及新版msg-meta内的已发出/送达/已读SVG图标，只检查发送前不存在的本次出站消息。未确认或仍显示时钟不计联系。2026-11-10已对真实登录账号验证号码搜索、联系人绑定与输入框就绪，未向真实号码重发；实际发送的回归验证在隔离模拟页完成。

## 群发联系人与间隔规则

客户默认全部不勾选。“全选”只勾选号码有效且距上次联系达到排除天数的客户；最低排除7天，单个未到期客户也不能选择。后端在创建任务、发送前再次校验，手动测试匹配已有客户时同样遵守7天限制。发送间隔以分钟填写，最低1分钟。

客户发送前核验WhatsApp联系人，新增或编辑为“客户名 国家”（空格分隔），例如Max Motorsport 南非。只有联系人同步保存并核验通过才发送；无法确认时停止该条。纯测试号码未匹配软件客户时不推测客户名称。

测试模式例外：输入号码测试不受7天联系限制和发送间隔限制，即使对应已有客户也可连续测试；车型客户群发继续执行最低7天、1分钟规则。


## 发送确认补丁

针对新版WhatsApp页面“文字只进入编辑框、图片停留预览”的情况，发送器现在会在按钮点击后检查草稿和新出站消息；文字若仍是草稿且没有新消息，会使用一次受保护的Enter回退动作。图片/附件会等待预览层的发送按钮和新的出站媒体消息。成功仍必须看到本次新消息的已发出、送达或已读回执；时钟、旧消息和入站消息都不会算成功。
